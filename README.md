# 📚 The Perfect Study Center

## 👨‍🏫 Overview
**The Perfect Study Center** ek educational platform hai jo **Class 10 students** ke liye bana hai.  
Yahaan milega full set of **objective questions & answers** exam preparation ke liye. 🚀

## 👔 Director
- **Dipak Kumar Peiyadarshi** 🙌

## 🎯 Purpose
- Class 10 ke students ko help karna objective questions practice karne me.  
- Easy access to study material online.  
- Free learning resource for board exam preparation. 💯

## ✨ Features
- 📖 Chapter-wise objective question bank  
- 🖥️ Simple & user-friendly interface  
- 🌐 Hosted on **Netlify** for fast access  

## 🔗 Website
👉 [Visit The Perfect Study Center](https://the-perfect-study-center-ry.netlify.app/)

---

### 🛠️ How to Use
1. Website open karo.  
2. Subject/chapter select karo.  
3. Objective questions practice karo directly online. ✅

## 💻 Tech Stack
- **Frontend:** React / Next.js  
- **Hosting:** Netlify
